# 社区地图原型

## 范围与设计依据

以用户创作的
[Community 画板](https://www.figma.com/design/3NdapDkKJcjjHElaAXDnX7/Fetarute-Website?node-id=209-202)
为视觉依据，沿用灰色画纸、纵向线路、进站斜线、横向联络线、头像马赛克、公园和河流。Landing 对应
`211:291`，玩家区对应 `211:289`，外部社群区对应
`211:290`。一张连续地图延伸到玩家区，但两区分别设站、独立分配成员，玩家不与外部伙伴混排。导视颜色复用
`railway.ts` 的 Discover
Line（SURC/DS）、浦蓝线（SURC/WS）和 PN（SURN/PN）。橙色斜线用连续 SVG 路径延伸到视口外，按头像墙实际边界提前转入竖轨，并为完整线宽预留间距；小屏将 DS 放在浦蓝线右侧，保留一致线宽、站点大小和安全边距，标题另留双线空间。站点圆由 CSS 伪元素绘制。地图不是实际游戏地理图或合作关系证明。

三种语言共用
`CommunityPage.astro`、静态数据与原生 TypeScript 控制器，没有新增框架或 island。直达地址是
`/zh-Hans/community/`、`/zh-Hant/community/`、`/en/community/`。原型标记
`noindex, follow`，Header 在首页旁并列「社区 ↗」主导航牌，手机更多菜单保留社区入口，桌面出口仅含外部服务。保留同页语言切换；暂不加入 sitemap，也不改动首页续行的施工中方向牌。`noindex`
不是访问控制。

## 资料边界

- `src/data/community.ts` 管理玩家、服务器／社区、外部团体三类地点。
- 首批样本复用首页已经公开署名的五位玩家及本地缓存头像；个人简介尚未收集，不编造人物偏好或引语。
- 每位愿意公开展示的玩家都可以独立录入，不要求拥有代表作品。当前从首页取样只是复用身份资料，不是入选规则。
- 三处外部伙伴均为明确占位，不提供虚构名称、合作关系或可点击网址。
- 简介占位、类别和交互提示集中在 `src/i18n/community.ts`，联系入口复用站点级 QQ 门户群。
- 头像马赛克由格子坐标与现有玩家数据在构建时生成，不依赖运行时图片服务；它是地图入口，不承担完整玩家名录功能。

正式发布前仍需收集个人介绍和展示意愿、核实外部伙伴资料，并决定是否增加可选作品／个人链接字段。长篇故事和活动资料如继续实现，应使用 Content
Collections，不在地图控制器里建立内容管理系统。

## 布局与交互约定

- 地块、河流、公园和街道共享 `src/data/community-map.ts`
  的逻辑坐标。先生成河岸和街道，再切分 L 形围合、矩形和梯形沿岸街块；手机使用独立的窄幅几何。
- 每次进入先生成穿城水道，再递归切分两岸土地：每片街区中的两条河岸保持平直、平行，垂直河岸方向的河宽为地图宽度的 6%；种子改变水道的位置与斜率，不制造细碎岸线起伏。两岸都保留可用地块，街道分叉方向、分割比例和地块形状仍随机变化，不保留固定行列。两区分别生成，成员只在所属区域分配。
- 每块土地需满足完整头像与姓名盒的最小标注空间：内接区域覆盖标注高度内的斜岸和 L 形凹口，而不只验证中心点。沿岸梯形也可从远离水面的直角围合公园；切出公园后空间不足的地块保留原轮廓，改从其他土地围合。无法切出八块的候选整图会按种子有界重试，极端情况使用已验证的后备布局，不强行缩小触控区域。
- 绿色公园、棕色学校、黄色广场和粉色文化空间随机占用未分配地块，配合站点既有 Phosphor 图标。`community-places.ts`
  保存用户确认的小水湾公园、蒲塘桥绿道公园、中州园、米子广场、湾岸广场、上浦大学、下渡港小学校和 Fetarute博物馆；保留原始地名，不臆造外语正式译名。名称真实但布局不表示实际相对位置。
- 河道从画面右侧流入，从左侧流出，屏幕内不露截断端面。河口和章节间的连接按实际 SVG 端点绘制，不再依赖地图右侧的固定背景；转折集中在街区之外的留白处。缩放、字体加载和文字换行时重新对齐连接，不重新生成土地。章节文字保留画纸底色，水面不能穿过笔画。
- Landing 的 DS 与浦蓝线保持 4–8px 边缘间距，随线宽而非视口横坐标增长；手机将 DS 放在浦蓝右侧，桌面放在左侧，换乘双圆始终水平对齐。
- `?mapSeed=123`
  可复现同一版布局。种子仅保存在本次页面 DOM，不使用本地持久化或访客标识。无脚本使用稳定构建期后备地图。
- 头像使用各地块内部的独立标注点，不落在 L 形包围盒的空缺里。空地仅作景观，不是虚构成员入口。
- CSS 多边形裁切同时决定绘制和点击边界；公园与河流不成为透明的矩形点击热区。
- 每区每八处地点延长一个街区，纯布局函数保留全部输入身份；hover、focus、点击、滚动和缩放不触发随机重排。贯通两区标题留白的河道让地图保持连续，PN 只在章节站点横向交会，不穿绕地块内部；交点按浦蓝线、PN、圆形站点从下到上叠放，上方蓝线与下方粉线各一枚圆标，圆心纵向相距一个线宽，表达同站换乘。
- 正文画纸、地块、文字和浮层消费全局 palette，跟随系统或手动外观选择；河流、公园、广场、学校和文化场所由
  `palette.ts` 提供深浅材料色。线路身份色保持不变，不在社区容器固定浅色值或 `color-scheme`。
- 所有地点面板统一为 **360 × 320 px**。窄屏统一收缩到
  `min(360px, 100vw - 32px)`，短屏统一限制到导航下方的可用高度；长正文在面板内滚动。
- 展开的是覆盖层，地块和邻居保持原有几何。优先放在地块右侧，空间不足翻到左侧，再限制于可见视口。
- 鼠标悬停、键盘聚焦预览；键盘会先将实际头像和姓名滚入可见区，不把仍露出外框的离屏标注当作已可见。点击／触屏首次点按固定展开。可以进入浮层阅读，通过关闭按钮、Escape 或外部点击关闭。
- 列车导览与首页共用 `TrainJourneyTooltip.astro` 完整面板，内部仍由 `HomeJourneyQuickPick.astro`
  绘制路线；社区由 `community-journey.ts` 通过 `routeStops`
  提供章节。浦蓝线贯穿全程，社区中心、世界与社群只标为换乘站，不改变主线颜色；两处站标复用首页的换乘胶囊。
- `train-feedback.css`
  统一首页路径车、换乘车与社区列车的偏色反馈；普通 hover、焦点和展开状态向当前线路色偏移，不绘制矩形框，高对比模式保留明确焦点轮廓。
- `train-tooltip-layout.ts`
  按实际字体测量全部站名，宽度至少保留首页的语言规格，再受可见视口边距限制。切站不会改变预选宽度，中文长站名不被地图资料面板的尺寸限制挤成两行。
- 列车站牌在正常尺寸一次显示全部章节；200% 缩放或极短屏放不下时，整张站牌允许原生滚动，超窄站名可换行。键盘聚焦会将站点或关闭按钮滚入可视范围，不再以隐藏溢出截掉末站；不拦截正常尺寸的页面滚动。
- `train-tooltip-interactions.ts`
  共用悬停确认、点击固定、滚动关闭预览、Escape 和焦点恢复；`train-journey.ts`
  共用当前站同步及 260ms 选中反馈后的跳站。减少动态时立即跳转。
- 社区列车只保留自身锚点与阅读进度计算，通过开关回调与地图地点互斥；短页尾滚不到屏幕中线时，以实际抵达底部判定最后一站。
- 页尾复用 `JourneyFooter.astro`
  的高度、标题、返回入口和品牌签名，社区只接入群号与复制操作以及左轨坐标。桌面最小高度 300px，小屏 320px；长文案允许自然增高。群号、复制操作横向排列，宽度不足时换行，反馈区域保留高度。页尾沿用首页的主题反色中性色对，纵向线路连续穿过页尾。
- 地图地点的原生 `details`
  保留无脚本展开能力，增强后使用 Popover 顶层；列车使用首页相同的固定对话框与 `aria-hidden` /
  `inert` 状态，无脚本时直接显示静态章节路线。
- BFCache 收起瞬时浮层，真正卸载取消监听器与待执行工作；异步复制结果不得写入已释放的页面。

## 验证方式

`npm run check` 包含原有全站检查、`test:community` 纯布局回归和 `test:static`
社区构建输出检查。浏览器测试沿用项目的 `node:test` 与外部 Playwright 依赖，不新增仓库测试运行时：

```bash
FETARUTE_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
FETARUTE_COMMUNITY_TEST_URL=http://127.0.0.1:4324 \
node --test test/community-map.browser.mjs

FETARUTE_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
FETARUTE_COMMUNITY_TEST_URL=http://127.0.0.1:4324 \
FETARUTE_TEST_BROWSER=webkit \
node --test test/community-map.browser.mjs
```

列车导览与首页同岸的接缝另有实际像素回归，覆盖两种像素密度及小数坐标相位：

```bash
FETARUTE_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
FETARUTE_HOME_TEST_URL=http://127.0.0.1:4324 \
FETARUTE_TEST_BROWSER=webkit \
node --test test/railway-seams.browser.mjs
```

可选 `FETARUTE_SCREENSHOT_DIR`
将截图写入指定目录。默认不写截图，不提交构建产物和浏览器报告。覆盖桌面 hover／键盘、390 × 844、320 ×
568、760 ×
390 触屏模拟、三语、减少动态效果、无脚本、浮层互斥和卸载后的复制边界。另覆盖 200 个种子的完整标注空间、换乘交点像素、河口实际跨出视口和小屏 DS 线距。布局稳定性使用文档坐标，不把浏览器为避开 Header 而自动滚动误报为重排。本机 Chromium／WebKit 结果不等于真实手机 Safari、屏幕阅读器或线上部署验收。
